## Findings

**Robustness:** every real Rigaku/PANalytical file in the dump read and analyzed without a
single crash. Peak positions and thicknesses are physically sensible throughout.

**Validations confirmed:**
- θ-2θ substrate peaks land on STO 100/200/300 (~22.75 / 46.47 / 72.57°) across S04, S05,
  S07, S08, S11 — matches first-principles values to <0.03°.
- **S25 XRR → d = 40.30 ± 0.44 nm (21 fringes, FFT cross-check 40.65 nm).** This validates
  the Kiessig-thickness path on Tushar's exact sample — the gap noted earlier is now closed
  on our side (still worth confirming against his reported number).
- XRR thicknesses scale sensibly with deposition shots (S04 ~4.6 nm @1000sh → S11 ~33 nm
  @20000sh → S25 ~40 nm @10500sh), and the "_updated" / "upto X deg" variants of the same
  sample agree with each other.
- φ scan: HP_TiO2 101 finds exactly 4 peaks (correct 4-fold for a cubic (100) cut).

**Issues surfaced (candidate follow-ups, not blocking):**
1. **3-fringe XRR fits report `± NaN` SE** (#5, #8, #19, #20). The quadratic Kiessig fit has
   3 coeffs, so 3 fringes leaves no DOF for a confidence interval → `polyfit` fallback with
   no SE. The thickness is still fine; the *uncertainty* is just unavailable. Consider
   reporting the FFT thickness as primary (or a clearer message) when fringes < 4.
2. **S11 rocking curves look anomalous** (#22, #23): centre ≈ 0.00° with FWHM ~0.63–0.67°
   (gauss) — ~5× broader than S05's film RC (0.14°), and the lorentz/gauss ordering is
   inverted vs every other RC. Likely a Δω-centred file with a broad pedestal the ±0.5°
   window over-captures, or a genuinely poor film. Worth an eyeball before trusting.
3. **Low default prominence over-segments sharp intense peaks** (#16 S10, #7 S06 report
   66–69 peaks; S10's top three are all within 0.14° of 46.5° — the Kα-split substrate peak
   counted several times). Not wrong, but a higher default `MinProminence` for θ-2θ would
   reduce noise picks.
   _Update 2026-06-12: fixed — `findPeaks` now defaults to a log-domain auto
   prominence with a unit-aware Poisson noise guard, and the GUI θ-2θ path adds a
   0.2° separation (Kα merge). The 66/69-peak blowups on S10/S06 are now 3/2 peaks;
   gated regression tests in `tests/testPeaks.m` pin S04/S05/S06/S10/S11. See
   `docs/superpowers/specs/2026-06-12-auto-prominence-design.md`._
4. **Single RSM `.xrdml` slices detect as `scanType = "unknown"`** (#28–30, #34). They read
   fine (255 pts each) but aren't recognized as RSM; area assembly needs `readXrdmlArea`.
